## 출처와 승인 구분

Copilot이 코드와 신규 테스트를 작성했지만 내부 `node --test`는 권한 거절로 실행되지 않았다. 사용자가 이후 별도 로컬 검증을 승인했고, 그 결과가 26개 통과 기록이다. 읽기 전용 Copilot 검토는 사람의 채택이나 운영 배포 승인이 아니다.

원본 로그·해시 기록·촬영 대상 코드는 수정하지 않고 보존한다. 저장소에는 세션 ID·개인 절대 경로를 가린 별도 사본을 포함한다. 가림 사본은 원본 해시로 검증할 수 없으며 변환 목록에 별도 해시가 있다.

## 남은 한계와 발표 전 확인

1. 한국어 내레이션을 사람이 직접 청취하지 않았다. 발표 컴퓨터에서 발음·음량을 확인한다.
2. PowerPoint/Keynote 네이티브 렌더링과 PPT 링크를 통한 MP4 실행은 미검증이다. 글꼴은 포함되지 않았다. 영상은 파일을 직접 열고, 슬라이드 배치가 다르면 PDF를 사용한다.
3. 전체 접근성 감사와 브라우저의 지연 응답 경쟁 조건 자동 검증은 수행하지 않았다. PDF는 태그 없는 문서다.
4. 후속 읽기 전용 정적 검토에서 시작 앱의 두 제약이 보고됐다. 런타임 재현 검증은 하지 않았으며 촬영본을 소급 수정하지 않았다.
   - 미리보기 요청이 일시 실패하면 같은 입력에 재시도 버튼이 없어 입력을 바꾸거나 페이지를 새로고침해야 한다.
   - 서버 파일을 심볼릭 링크로 실행하면 시작점 비교 때문에 서버가 뜨지 않을 수 있다. 안내된 `npm --prefix … start`로 실제 경로에서 실행한다.
5. 테스트 통과와 결함 미발견 의견은 실서비스 품질 보증이 아니다. 합성 데이터·localhost·모의 전송만 구현했으며 인증·실제 발송·운영 배포는 없다.

## 비공개 저장소 전달

제작 완료 후 사용자가 `junwoojeong100/ghcp-agentic-dev-cc` 비공개 저장소 생성·커밋·푸시를 별도로 요청했다. 이는 결과물 전달이며 데모 앱의 운영 배포와 다르다. 실제 전달 완료 여부는 저장소와 최종 응답의 커밋 식별자로 확인한다.
