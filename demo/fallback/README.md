# 검증된 변경본 보관

이 폴더는 실제 Copilot 변경 후 별도 로컬 테스트를 통과한 `demo/run`의 소스·테스트·실행 설정을 그대로 복사한 보관본입니다. 새로 구현하거나 Copilot을 다시 실행한 결과가 아닙니다.

- 이익률 15% 미만 견적의 모의 전송 차단, 서버 검증, UI 차단 사유가 포함돼 있습니다.
- 복사 파일은 `evidence/copilot-run/local-test-record.json`의 경로별 SHA-256과 대조했습니다.
- 테스트 기록: 별도 로컬 실행 26개 통과. Copilot 내부 테스트 실행은 권한 거절로 미실행이었습니다.
- 기능별 사용법과 발표 방법은 프로젝트 최상위 `README.md`, `docs/presenter-guide.md`를 참조하세요.

프로젝트 최상위에서 `PORT=4412 npm --prefix demo/fallback start`를 실행하고 `http://127.0.0.1:4412`을 엽니다. 포트가 사용 중이면 다른 빈 포트를 선택하세요. 외부 발송 없이 합성 데이터로만 동작합니다.
