# 실제 Copilot 변경 작업본

이 폴더는 준비된 시작 앱에 Copilot CLI가 **15% 미만 이익률 견적 전송 차단**을 추가한 결과입니다. 화면과 서버가 동일한 서버 판정을 사용합니다. 데이터는 합성이며 모의 전송만 합니다.

프로젝트 최상위에서:

```sh
PORT=4411 npm --prefix demo/run start
npm --prefix demo/run test
```

첫 명령 실행 후 `http://127.0.0.1:4411`을 엽니다. 포트가 사용 중이면 다른 PORT를 지정하세요.

- Q-1001 / 할인 10% → 차단, 할인 0% → 허용
- Q-1500 / 할인 0% → 정확히 15%, 허용
- Q-1499 / 할인 0% → 원가 1원 증가, 차단

[변경 요청](change-request.md), [실행 근거](../../evidence/copilot-run/README.md), [발표 가이드](../../docs/presenter-guide.md)를 참고하세요.

과거 `README.md`와 `handoff/` 원본은 구현 당시 해시에 포함된 자료로 제작 환경에만 보존합니다. 이 안내는 촬영 후 추가한 문서이며 Copilot이 작성한 코드 변경으로 계산하지 않습니다. 새로 Copilot을 실행하면 다른 결과가 나올 수 있으며, 현재 기록은 과거 실행의 증거입니다.
